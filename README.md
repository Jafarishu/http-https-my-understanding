
# Understanding HTTP vs HTTPS

A simple and clear documentation explaining the core differences between HTTP and HTTPS protocols, written during my Web Development and Cyber Security learning journey.

---

## 🌐 What is HTTP?
* **HTTP** stands for **Hypertext Transfer Protocol**.
* It is the foundational protocol used to transfer data across the web.
* **Security Risk:** Data sent via HTTP is transmitted in **Plain Text**. If a hacker intercepts the network, they can easily read passwords, credit card numbers, or personal messages.

---

## 🔐 What is HTTPS?
* **HTTPS** stands for **Hypertext Transfer Protocol Secure**.
* It is the highly secure version of HTTP.
* **Security Feature:** It uses **SSL/TLS Encryption** to convert sensitive data into a secret code. Even if a hacker steals the data, they cannot understand or decode it.

---

## ⚡ Key Differences

| Feature | HTTP | HTTPS |
| :--- | :--- | :--- |
| **Security** | Unsecure (Plain Text) | Highly Secure (Encrypted) |
| **Privacy** | Vulnerable to hackers | Protected from hackers |
| **Browser Indicator** | Shows "Not Secure" warning | Shows a **Padlock (Lock) Symbol** |
| **SEO Advantage** | Lower ranking preference | Higher Google search ranking preference |
